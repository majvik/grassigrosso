# Пакет документов для обновления юридических страниц

## Цель

Подготовить внутри принятого клиентом комплекта отдельную папку `to update` с исходниками, которые затем будут использованы при обновлении сайта.

## Источник истины

Принятые клиентом файлы из `client-documents/personal-data-policy/corrected/`:

- `01-privacy-policy.md`;
- `02-web-form-consent.md`;
- `03-cookie-and-analytics.md`;
- `Grassigrosso-form-withdrawal-of-consent.docx`;
- `Grassigrosso-form-data-subject-request.docx`.

## Состав результата

- три Markdown-файла для страниц политики, согласия веб-форм и cookie;
- два отдельных бланка DOCX для скачивания пользователями сайта;
- объединённый DOCX-комплект не включается, поскольку источником страниц служит Markdown.

## Ограничения

- содержание принятых документов не редактируется;
- в Markdown не добавляется служебная разметка выделения;
- в DOCX удаляется жёлтое выделение, остальное форматирование сохраняется;
- исходный код сайта в рамках задачи не изменяется;
- папка остаётся под существующим правилом `.gitignore` для `client-documents/`.

## Критерии готовности

- все пять файлов находятся в `client-documents/personal-data-policy/corrected/to update/`;
- Markdown совпадает по содержанию с принятыми источниками;
- в DOCX отсутствуют элементы `w:highlight`;
- DOCX открываются, сохраняют нумерацию страниц и проходят визуальную проверку всех страниц.
