# Правила маппинга: печатный каталог → slug'и фильтров

## Жёсткость (шкала 1–10, стр. `pdf/4.pdf`)

1. Если **сторона 1 ≠ сторона 2** → `dualFirmness`.
2. Если стороны равны:
   - 1–3 → `soft`
   - 4–6 → `medium`
   - 7–10 → `hard`

В MD сохраняются `firmness_side1`, `firmness_side2` и итоговый `firmness`.

## Нагрузка

Из поля «Максимальная нагрузка на одно спальное место» (кг) → `load_range`:

| max_load_kg | load_range |
|-------------|------------|
| ≤ 120 | upTo120 |
| 121–160 | upTo160 |
| 161–180 | upTo180 |
| > 180 | over160 |

**Топеры:** нагрузка в каталоге часто не указана → `max_load_kg: 120`, `load_range: upTo120` (с пометкой в «Примечания маппинга»).

## Высота

| height_cm | height_range |
|-----------|--------------|
| ≤ 16 | low |
| 17–22 | mid |
| ≥ 23 | high |

## Тип конструкции

| Условие | mattress_type |
|---------|---------------|
| Раздел «Топеры» (`pdf/46`…) | `topper` |
| В слоях есть «пружин» | `spring` |
| Иначе | `nospring` |

## Коллекция

| PDF-диапазон / маркер | collection |
|-----------------------|------------|
| Classic | `classic` |
| Flexi | `flexi` |
| Relax (до Trend) | `relax` |
| Trend | `trend` |
| Топеры | `topper` |

**Особый случай:** модель «Релакс» в коллекции Trend → slug `relax-trend`, `collection: trend`.

## Наполнители (filling_slugs)

| Текст в каталоге | Slug |
|------------------|------|
| кокосовая койра | coir |
| memory foam, эффектом памяти | memoryEffect |
| neolatex, латекс | latex |
| flexi, elax, высокоэластичная пена, орто, карбон, повышенной плотности | orthoFoam |
| нано-пена | nanoFoam |
| форплит | forplit |

Слои без slug (термовойлок, войлок, бикоттон, пружинный блок и т.д.) — только в секции «Наполнение» MD.
