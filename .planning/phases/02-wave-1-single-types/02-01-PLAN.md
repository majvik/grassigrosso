- Work only in the local workspace. Do not push, open/update a PR, deploy, or mutate Timeweb/dev/prod.

- The phase cannot be marked complete until all new tests and the full relevant local verification suite pass and exact commands/results are recorded below.

### Task 1 — Freeze full content contract (hard gate)

Create `02-CONTENT-CONTRACT.md` by inventorying every value in the six current page renders and all associated runtime hooks. Classify each value as CMS-owned or code-owned with justification. Include representative fixture values.

Verify: every hardcoded editor-facing string/media/repeated item is mapped; Index collections/testimonials, Hotels categories/products/discounts, Dealers packages, Contacts per-office maps and Documents stable ids are explicitly covered. Stop if the matrix has unresolved rows.

### Task 2 — Finalize components from the contract

Create the already approved primitives (`hero-media`, `stat`, `geo-city`, `office`, `document-card`, `contact-info`) plus the layout-specific components required by Task 1. Do not force structured cards/tables/media into `page.section` or `page.list-item`.

Verify with automated schema-contract tests: JSON valid; no circular component graph; stable keys and media constraints represented; ordering has one source of truth.

### Task 6 — Regression and scope guard
